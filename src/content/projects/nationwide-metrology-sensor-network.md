## Project Overview

As Field Calibration Coordinator with API Metrology (contracted to SIMCO), managed and executed multi-state NIST-traceable sensor calibrations across national parks (Yosemite, Death Valley, Joshua Tree, Sequoia, Shenandoah), BLM lands, agricultural test stations, and industrial facilities.

### Key Technical Contributions
- **Multi-Sensor Calibration**: Performed field baseline calibrations and verification on dielectric probes, electromagnetic ground meters (Geonics EM31/EM34), cosmic-ray neutron sensors, and ambient gas monitors ($O_3$, $SO_2$, $NO_2$).
- **SOP Standardization**: Authored standardized operating procedures and training runbooks for field technicians operating in remote environments.
- **Logistics & QA/QC**: Managed mobile instrumentation inventories, spare sensor stocks, reference standards, and 30-day post-visit technical reporting.
