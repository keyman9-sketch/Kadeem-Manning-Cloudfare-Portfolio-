## 1. ALCOA+ Core Data Integrity Principles

```
  Attributable   ──> Who performed the analysis, measurement, or maintenance?
  Legible        ──> Can entries be clearly read throughout the record lifecycle?
  Contemporaneous──> Was data recorded at the exact moment of execution?
  Original       ──> Is this the primary raw recording or true certified copy?
  Accurate       ──> Is data truthful, without undocumented post-edits or omissions?
```

## 2. Standardized Correction Protocol

When correcting handwritten log entries in laboratory notebooks:

1. **Single Strike-Through**: Draw a single horizontal line through the incorrect text (`incorrect entry`).
2. **Never Obliterate**: Never use correction fluid (white-out), erasers, heavy cross-hatching, or page excision.
3. **Annotate Correction**: Write the correct value immediately adjacent, accompanied by the **technician initials, date, and reason code** (e.g., `EE = Entry Error`, `CE = Calculation Error`).

```text
Example:
Target Pressure: 1.2 x 10^-5 mbar [KM 2021-12-14 EE: transcribed from ion gauge channel 2]
```
